# СГУГиТ Расписание — Telegram-бот

Telegram-бот для студентов и преподавателей СГУГиТ (Новосибирск). Основные функции: расписание, задания, поиск преподавателей, уведомления, групповые чаты, Inline Mode и административная панель.

**Стек:** Python 3.11, aiogram 3, SQLite или PostgreSQL (asyncpg).

## Возможности

### Расписание
- Расписание на сегодня, завтра, неделю и выбранную дату; переход по календарю.
- Следующая и текущая пара, чётность недели, подгруппы.
- Просмотр расписания другой группы.
- Автоматическая синхронизация с сайтом СГУГиТ и хранение расписания в базе.
- Снимки расписания, ручной импорт CSV/XLSX и откат к снимку.
- Отображение времени, предмета, преподавателя, аудитории и типа занятия.
- Экспорт расписания в календарь .ics.

### Вопросы обычным языком
В личном чате и привязанной группе можно спрашивать, например:
- «Какие завтра пары?», «что у нас в пятницу?», «расписание на следующей неделе».
- «Когда первая пара?», «во сколько заканчиваем?», «сколько завтра пар?».
- «Где вторая пара?», «кто ведёт физику?», «когда следующая математика?».
- «Будет ли завтра МГП?», «в какой аудитории геодезия?».
- «Что изменилось в расписании?», «какие изменения на завтра?», «что перенесли?».
- «Что задали по физике?» и другие вопросы о заданиях.

Распознавание использует правила, словарь предметов и пользовательские синонимы. Для преподавателей доступен поиск по фамилии и инициалам.

### Задания
- Общий список заданий группы и отображение заданий рядом с соответствующими парами.
- Добавление через меню и короткой фразой, например: «дз математика №15–20 к пятнице».
- **Автоматический сбор из группового чата:** если бот добавлен в чат, чат привязан к учебной группе, а сообщение явно обозначает домашнее задание и содержит распознанный предмет из расписания этой группы, бот сохраняет его в разделе заданий. При наличии подходящей пары задание связывается с ближайшим занятием по этому предмету.
- Автоматическое распознавание не должно срабатывать на обычные сообщения о расписании без признаков задания; одинаковые сообщения не создают повторные записи в течение суток.
- Срок сдачи, отметка «сделано», редактирование текста/предмета/срока и вложения (фото и документы).

Автоматический сбор работает в привязанных групповых чатах, где бот получает текстовые сообщения. Для корректного распознавания предмет должен присутствовать в расписании группы или словаре синонимов. Если сообщение сформулировано неоднозначно или не содержит конкретного описания задания, бот его не сохраняет.

### Изменения расписания
- В привязанном групповом чате бот распознаёт предложения об отмене, добавлении и переносе занятия.
- Перед применением показывает черновик и просит подтвердить изменение.
- Принятые изменения учитываются в расписании группы.
- Вопросы «что изменилось?» и «что перенесли?» показывают подтверждённые изменения за последние две недели и ближайший месяц; при указании даты — изменения за этот день.

### Уведомления
- Вечерняя сводка на следующий день.
- Напоминание перед парой.
- Уведомления об изменениях расписания в личные сообщения и привязанные групповые чаты; учитываются пользовательские настройки, повторная обработка одного события не создаёт повторную рассылку.
- Независимые личные настройки и настройки группового чата.
- В группах сводка может закрепляться до начала первой пары; доступны настройки автоудаления и приватных ответов.

### Групповые чаты и Inline Mode
- Привязка группового чата к учебной группе.
- Команды /today, /tomorrow, /week, /next, /hw, /schedule, /homework, /group, /settings, /help.
- Умные ответы по упоминанию бота, ответу на его сообщение или ключевым фразам — в зависимости от настроек чата.
- Inline Mode: @имя_бота ИС-11, @имя_бота Иванов, @имя_бота преподаватель Иванов. Можно указать день или дату.
- Для Inline Mode не требуется добавлять бота в чат.

### Преподаватели
- Кабинет преподавателя с расписанием на день, неделю и выбранную дату.
- Поиск ближайшей пары, коллег и свободных аудиторий.
- Справочник подразделений и кабинетов.
- Рейтинг преподавателей с оценками и модерацией отображения.

### Административная панель
- Статистика, пользователи, диалоги и обращения.
- Управление расписанием, справочником, заданиями и рейтингом.
- Рассылка, словари предметов, синонимы и тексты интерфейса.
- Журнал действий, резервное копирование, восстановление и экспорт.
- Отдельный раздел групп бота: список сохранённых чатов, поиск, карточки групп, аватарки, число участников, настройки и журнал событий.

Telegram Bot API не предоставляет метод для получения полного списка всех чатов, в которых состоит бот. Поэтому админский список формируется из сохранённых записей; новые добавления и удаления фиксируются автоматически. Группы, которые не были сохранены до включения такого учёта, нельзя обнаружить задним числом через Bot API.

## Быстрый запуск

Подробная инструкция по GitHub и Bothost: docs/DEPLOY.md.

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN и SUPERADMIN_ID
python -m app.main
```

В репозитории есть Dockerfile. Для Bothost используйте существующее Persistent Storage и не меняйте путь к базе данных при обновлении приложения.

Форматы файлов импорта: docs/IMPORT_FORMAT.md. Особенности парсера: docs/SITE_PARSER.md.

## Проверки

```bash
python -m unittest discover -s tests -t .
python tools/check_names.py
```

GitHub Actions дополнительно выполняет компиляцию Python-файлов и unit-тесты при push в main и при создании Pull Request.

## Текущее состояние

- Проверка бота в реальном Telegram и работоспособность парсера сайта подтверждены владельцем проекта.
- Автоматическая обработка расписания сохраняет данные в БД; при недоступности источника бот продолжает показывать последнее сохранённое расписание.
- Схема БД развивается версионными миграциями в app/db/schema.py; новые миграции для автоматического сбора заданий из группового чата не требуются.
- Режим хранения: SQLite или PostgreSQL. Для PostgreSQL требуется доступный сервер и корректный DATABASE_URL.
- Перед восстановлением резервной копии рекомендуется сохранить текущую копию базы.

## Настройка Inline Mode

Включите Inline Mode через @BotFather → /setinline и задайте подсказку, например «Введите группу или фамилию преподавателя». После этого используйте @имя_бота ИС-11 или @имя_бота Иванов в любом чате.
