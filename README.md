# СГУГиТ Расписание: Telegram-бот

Бот для студентов СГУГиТ (Новосибирск): расписание, задания группы, рейтинг преподавателей, поиск преподавателя,
ответы на вопросы обычными словами, админ-панель. Python 3.11, aiogram 3, PostgreSQL/SQLite.

## Возможности
- **Расписание:** сегодня, завтра, неделя, любая дата (календарь), следующая пара, чётность недель, подгруппы,
  чужая группа, экспорт в календарь (.ics). Группа запоминается один раз.
- **Синхронизация расписания:** бот читает каталог СГУГиТ и автоматически загружает каждую группу по её отдельному URL `/raspisanie/group/<id>/`; список URL не нужно заполнять вручную. Расписание хранится в БД, синхронизируется в фоне, есть снимки и откат, ручная загрузка
  CSV/XLSX, ручные пары старосты. Если сайт недоступен, бот показывает сохранённое и пишет админу.
- **Уведомления:** вечерняя сводка на завтра, напоминание перед парой, изменения расписания (было → стало); каждое можно отключить (в личке, в настройках чата и глобально админом). В группах вечерняя сводка закрепляется до начала первой пары.
- **Вопросы текстом** (личка и группы): «какая завтра первая пара?», «какие пары завтра?», «где вторая пара?»,
  «кто ведёт физику?», «а завтра будет мгп?» (аббревиатуры предметов определяются сами, синонимы добавляет админ).
- **Где найти преподавателя:** «где найти препода Крылова?» → идущая или ближайшая пара (аудитория, группа) +
  структурное подразделение и кабинет из справочника вуза.
- **Групповые чаты:** автоматическая привязка к группе добавившего студента; если он зарегистрировался позже, группа привяжется при `/settings` или `/help`. Команды `/today`, `/tomorrow`, `/week`, `/next`, `/hw` (также `/schedule`, `/homework`), `/group`, `/help`; умные ответы по упоминанию, ключевым фразам или в активном режиме (бот ждёт ответа одногруппников и отвечает сам, если никто не ответил). Настройки чата доступны добавившему бота, старосте своей группы и администраторам чата. Можно включить вечернюю сводку и автоудаление ответов.
- **Задания:** быстрый ввод («дз математика №15 к пятнице»), одобрение старостой, отметка «сделано», 📎 в расписании.
- **Рейтинг преподавателей:** 1–5 звёзд, страницы по 6, поиск, минимум голосов для показа, админ скрывает раздел.
- **Роли:** главный админ (ID только в `SUPERADMIN_ID`, скрыт), админы с урезанными правами, старосты (заявка или назначение,
  после отказа кнопка пропадает, снять блок может главный админ), студенты. Проверка ФИО отсеивает мусор.
- **Админ-панель:** статистика, пользователи, заявки, очередь ФИО, расписание, справочник, рассылки, настройки,
  словари, журнал действий, бэкап/восстановление, экспорт в Excel.

## Честно о состоянии проекта
- Бот **не запускался в живом Telegram**. Логика (ФИО, вопросы, БД на SQLite, импорт, синхронизация, все экраны и
  сценарии меню/админки, групповые сценарии) проверена тестами; слой aiogram (`app/bot/tg.py`) проверен на заглушке
  aiogram с поддельным ботом. Вызовы настоящего aiogram и PostgreSQL (asyncpg) в тестах не выполнялись.
  Первый запуск лучше сделать на тестовом боте и тестовой БД.
- **Страницы сайта вуза** (`/raspisanie`, `/teachers/`) не удалось открыть при разработке, поэтому разбор эвристический
  и проверен только на образцах. Пока он не подстроен, пользуйтесь загрузкой файлами.
- **Не реализовано из ТЗ:** вложения (фото, файлы) к заданиям и редактирование заданий (только удаление и новое),
  редактор текстов интерфейса в админке, webhook, Redis, Alembic (свои версионные миграции в `app/db/schema.py`),
  правка расписания администратором вручную (есть у старост и загрузка файлом).
- Состояние диалога хранится в БД и переживает перезапуск. Уведомления приходят отдельными сообщениями.

### Поиск группы и добавление бота в чат
В приветствии и главном меню доступна кнопка «➕ Добавить в группу», которая открывает стандартный экран Telegram для добавления бота в групповой чат. Поиск групп принимает разные разделители и регистр, включая `Э-22.1`, `э221`, `Э 22 1`; при наборе на латинской раскладке `e221` дополнительно проверяется вариант `Э-22.1`, если точная группа на «Е» не найдена. Если точной группы нет в каталоге, бот может предложить похожие группы для ручного выбора.

### Inline-режим

Включите Inline Mode для бота через `@BotFather` → `/setinline` и задайте подсказку, например «Введите группу, например ИС-11». После этого в любом чате можно написать `@имя_бота ИС-11`, выбрать результат и вставить расписание на сегодня. Добавлять бота в этот чат не требуется. Результаты строятся по последнему расписанию в базе; если расписание устарело, откройте бота напрямую, чтобы увидеть предупреждение о свежести.

### Редактирование интерфейса и задания

Главный администратор: `/admin` → «Тексты интерфейса». Можно изменить основной текст, приветствие, сообщение для нераспознанного вопроса, название кнопки спонсора и её ссылку. В карточке задания автор или администратор может изменить текст, предмет, срок, а также заменить или удалить вложение.

### Уведомления и аналитика

В «Ещё → Уведомления» можно задать собственное время сводки и интервал напоминания перед парой. В админской статистике отображаются события за 7 дней, популярные типы действий и ориентировочная доля неотвеченных вопросов. Для точной аналитики по смысловым классам вопросов потребуется расширить классификацию NLU.
