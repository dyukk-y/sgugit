# Changelog

## Anti-spam protection
- Added per-user rate limits for private messages, group messages, and inline-button callbacks.
- Repeated identical text/media messages are detected within a 20-second window.
- Escalating temporary cooldowns: 10 seconds, 1 minute, then 10 minutes for repeated violations.
- Private users receive a throttled warning; group chats are not flooded with warning messages.
- Anti-spam counters are in-memory and reset on restart; this is intended for ordinary spam prevention, not persistent sanctions.

## Исправления запуска и распознавания групп
- В личном чате ответ теперь отправляется/обновляется до удаления команды пользователя, поэтому `/start` не исчезает раньше ответа.
- Добавлена защита от повторной обработки одного сообщения в обработчиках личного чата; это предотвращает двойной показ меню при пересечении обработчиков.
- Регистрация принимает только название группы строгого формата: две буквы + две цифры, с необязательной подгруппой. Варианты `МД-22.1`, `мд22.1`, `мд221`, `мд-221` приводятся к `МД-22.1`.
- При синхронизации каноническое имя группы сохраняется и для ранее созданной записи.


## Исправление загрузки расписания (2026-10-18)
- Автоматическая синхронизация запускается сразу при старте, без начальной задержки.
- Если база групп пуста, регистрация запускает синхронизацию и повторно ищет группу до показа ошибки.
- Парсер официального HTML стал менее зависим от строгой вложенности блоков `.date_info`, `.day` и `.day_hours`.
- При неудачной загрузке пользователь получает техническую причину из статуса синхронизации, если она есть.

## Каталог групп: резервное обнаружение URL
- Если каталог `/raspisanie/` не содержит ссылок на группы, бот теперь проверяет страницы `/raspisanie/group/<id>/` в диапазоне ID 1550–1900 и подтверждает страницу по заголовку `Группа ...`.
- Найденные URL сохраняются в `data/group_urls.json`, чтобы не повторять полный перебор при каждом плановом обновлении.
- При проверке поддерживаются и названия групп, начинающиеся с цифры, например `1БМ.1`.
- Ограничение: ID вне диапазона 1550–1900 не будут найдены этим резервным способом; при необходимости диапазон можно расширить.

- Нормализация групп поддерживает однобуквенные коды, включая `Э-22.1`, и варианты `э221`, `Э 22 1`, `э-221`.
