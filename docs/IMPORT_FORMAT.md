# Формат файлов для загрузки

Файлы `.csv` (разделитель `;`, `,` или табуляция; кодировка UTF-8 или Windows-1251) и `.xlsx` (первый лист).
Первая строка может быть заголовком. Примеры: `docs/examples/`.

## Расписание (Админ-панель → Расписание → Загрузить файл)
Колонки: `группа; дата; пара; начало; конец; предмет; преподаватель; аудитория; тип; подгруппа`.
- обязательные: группа, дата, начало, конец, предмет;
- дата: `2026-10-20` или `20.10.2026`; время: `08:30`;
- пара: номер (если пусто, нумеруется по порядку); подгруппа: 1, 2 или 3 (пусто = всем);
- при любой ошибке в файле **ничего не загружается**, бот показывает первые ошибки;
- загруженные занятия помечаются ✏️ и не перезаписываются автосинхронизацией с сайта;
- для групп и дат из файла прежние ручные занятия заменяются новыми.

## Справочник преподавателей (Админ-панель → Расписание → Справочник преподавателей → Загрузить файлом)
Колонки: `ФИО; Подразделение; Кабинет` (кабинет относится к подразделению; достаточно указать его один раз).
После загрузки файлом автообновление справочника с сайта отключается, пока вы не нажмёте «Обновить с сайта».
